# 🌍 Dashboard de Indicadores Demográficos y Socioeconómicos Mundiales (Power BI)

## 📌 Descripción del Proyecto
Este proyecto consiste en un reporte interactivo desarrollado en **Power BI** para analizar indicadores demográficos, de salud y desarrollo socioeconómico a escala global, cubriendo una población de más de 7.400 millones de personas. 

El objetivo es facilitar la exploración visual de datos geográficos y correlaciones clave como la esperanza de vida versus la mortalidad infantil por continente y país.

## 📊 Estructura del Reporte

### 1. Análisis de Población por Continente y País
- **Visualizaciones clave:** Treemap de densidad poblacional, mapas globales interactivos por rango de población y tablas resumidas.
- **Funcionalidad:** Filtros dinámicos por continente (África, América, Asia, Europa, Oceanía) y rangos poblacionales (de 0-1M hasta +100M).


### 2. Indicadores de Salud y Esperanza de Vida
- **Visualizaciones clave:** Gráfico de dispersión (Scatter Plot) de *Esperanza de Vida vs. Mortalidad Infantil*, matriz de indicadores por país y mapas temáticos.
- **Análisis de Valor:** Identificación de brechas de desarrollo y detección de patrones regionales críticos en salud pública.


## 🛠️ Herramientas y Tecnologías Utilizadas
- **Power BI Desktop:** Modelado de datos, creación de medidas y diseño de interfaz visual.
- **Mapas interactivos:** Integración con servicios de mapas de Bing para geolocalización.
- **Filtros e Interactividad:** Segmentadores sincrónicos entre páginas para navegación fluida.
